個人の技術的な記録を置く場所として、このサイトを作りました。

目指したのは、文章を書くことから公開までの距離が短いことです。記事は Markdown で書き、変更を Git に積む。それだけでサイトが更新される構成にしています。

## なぜ Zola なのか

Zola は単一の実行ファイルで動く静的サイトジェネレーターです。依存関係が少なく、ビルドが速い。テンプレートと Markdown の関係も素直で、自分の手に収まる感覚があります。

```bash
zola serve
```

このコマンドでローカルサーバーが立ち上がり、原稿を保存するたびにプレビューへ反映されます。

## ここに書くこと

日々の実装で得た知見、使っている道具の設計、うまくいかなかった試みも含めて残します。完成品だけでなく、考えた過程があとから役に立つ場所にしていく予定です。
